# opsmill-sdd

The OpsMill spec-driven development workflow for every repo:

- the `opsmill` extension: `auto`, `prep`, `implement`, `extract`,
  `retrospect`, `summary` and `qa`
- the `checkpoint` extension, which `prep`, `implement` and `auto` commit with
- the `critique` extension with the `critique-opsmill` preset
- the `reconcile` extension with the `reconcile-opsmill` preset

Install and upgrade: see the
[opsmill-speckit README](https://github.com/opsmill/opsmill-speckit#install).
